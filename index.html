Modular robotics

Seven modules. Any robot. One controller.

Build the robot the task needs. Rebuild it when the task changes.

01

Seven modules

Joint and Link build the kinematics. The Hub is the root. Battery and Wheel make it mobile. One sensor, one Hand, and standard tools bolt onto any Joint.

02

The Port

One interface on every module. Any Port mates with any Port: load, power, data, safety.

Load
Quarter-turn bayonet, no tools, under 10 s.
Power
48 V DC through every Port.
Data
Single-pair Ethernet, clocks synchronised.
Safety
Hardwired stop loop through every module.
Tools
ISO 9409-1 bolt pattern on the face, so standard tools bolt on.
03

Six robots, one stock of parts

Take one robot apart, build the next.

04

One controller for every body

One network for every robot. Each robot tells it what it is built from.

Our first results with a learned controller, in simulation, are positive and being prepared for publication.

Our target is a robot doing a new task within four hours of unpacking the parts, taught with at most five demonstrations and without code.
